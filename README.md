# Racio_1bot · v5

Telegram-сигнали на **наявних 21 FX-парах**. Лише закриті 5m-свічки (прогрів 200 барів, свіжість ≤180 с).

| Пресет | Умова CALL / PUT | Фіксована експірація | Research holdout (незалежний запуск) |
|---|---|---|---|
| REV_RSI14 | RSI14 <20 / >80 | 60 хв | n=276 / 67.03% |
| REV_BB3 | close поза BB20 ±3σ + RSI14 <30 / >70 | 60 хв | n=351 / 65.24% |
| REV_RSI7 | RSI7 <15 / >85 | 45 хв | n=921 / 60.80% |

RSI: RMA (`ewm(alpha=1/n, min_periods=n)`, adjust=True); BB: population std (ddof=0).
Пріоритет одного бару: RSI14 → BB3 → RSI7. Без перекриття відкритих угод пари/пресету (пам’ять + PENDING/PROCESSING у PostgreSQL).
Збережено новинну паузу, SignalGate (дедуплікація, конфлікти, експозиція), SegmentFilter, контроль свіжості та несприятливого руху >0.5 ATR.
Чотири confluence-стратегії вилучені: попередній спільний тест дав 6619 угод / 49.09%. Їхні старі ключі конфігурації ігноруються; історія БД зберігається.
AI/ML не оцінюють вхід і не змінюють експірацію. Опціональний Gemini — лише текстовий огляд закритої угоди, не доказ причин результату.

## Експериментальний фільтр сесій — за замовчуванням OFF

Один глобальний перемикач, пресети за замовчуванням ON; є попарна персоналізація.
Сесії визначаються за часом закриття сигналу, із DST: London 08–16 Europe/London, NY 08–16 America/New_York; спільні години = Overlap; Asia 00–07 UTC поза ними; решта = Other.
Discovery-вибір: RSI14 дозволяє London+Overlap+Other; BB3 — NY+Other; RSI7 — London+NY+Overlap+Other.
Це не збільшення кількості сигналів: фільтри скорочують потік, а значна частина історичного покращення припадає на позасесійні години.

## Telegram

- 📡 Сигнал зараз; 🤖 Автоскан ON/OFF; ⏳ Активні угоди; 📜 Історія (15 результатів); 📊 Статистика; ⚙️ Стратегії.
- Картка: напрямок, пресет, ціна, RSI, сесія, фіксована експірація та час UTC/Київ.
- WIN/LOSS/NEUTRAL/VOID додаються до оригінальної картки; також коротке повідомлення-відповідь.
- Статистика лише цього чату: загальна, пресети, топ/низ пар; WR з n і 10-блоковим індикатором. Періоди: сьогодні (Київ), останні 7/30 днів, все. WR враховує лише CLOSED WIN/LOSS; NEUTRAL/VOID виключені.
- Щоденний звіт о 21:00 Europe/Kyiv лише чатам з увімкненим автосканом. Автоскан-список зберігається в пам’яті до рестарту.
- Глобальні/попарні перемикачі, лабораторія та експорт захищені ADMIN_IDS. Якщо список порожній — керування доступне всім (попередня поведінка).

## Запуск та дослідження

Python ≥3.10, `pip install -r requirements.txt`; змінні TELEGRAM_TOKEN, DATABASE_URL, FINNHUB_TOKEN (або FINNHUB_API_KEY), ADMIN_IDS (ID через кому). Опціонально GEMINI_API_KEY для ретроспективного огляду.
Запуск: `python3 bot.py`. PostgreSQL ініціалізується при старті; закриття відновлюються через фонову перевірку.
`/backtest EUR/USD` або `/backtest ALL`: Yahoo 5m/60d, REV-only, порівняння сесій OFF/ON з поточними перемикачами пресетів; точні open входу/експірації, пропуски й нічиї виключені. Без історичних новин, SegmentFilter та затримки виконання.
Для офлайн-історії: `backtest.simulate_reversion_pair(pair, df_5m, strategies_status=..., start=..., end=...)`; передайте також історію до start для прогріву.
`/lab_run`, `/lab`, `lab.py` — окрема дослідницька лабораторія; не джерело live-сигналів. `/export` — CSV для адміністратора.
Перевірка: `python3 -m py_compile *.py`, `python3 -m unittest discover -v`.

**Research не гарантує живий WR.** Числа таблиці — holdout 20 жовтня–10 листопада 2026 на 21 корельованій парі, лише 16 денних кластерів після пошуку багатьох конфігурацій. Потоки не можна додавати. Комбінація з пріоритетом раніше дала 1218 / 60.84%, а не 65%. Yahoo та брокерські ціни відрізняються; потрібен новий forward-test на фактичних цінах виконання. Для виплати 85% беззбиток ≈54.05%.
